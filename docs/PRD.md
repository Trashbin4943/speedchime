# SpeedChime PRD 요약 (초안, 2026-11-13)

## 목표 (MVP)
- GPS 기반 실시간 속도 표시 (kph)
- 기준 속도 100/120/140kph 중 선택, 기본 120
- 기준 초과 시 차임 자동 반복, 기준 아래로 내려오면 자동 정지
- 내비게이션 앱이 앞에 떠 있어도(백그라운드) 동작

## 비목표
회원가입·서버·주행 기록 / OBD·단속 카메라 / 임의 기준 속도·커스텀 사운드·알림 속도 표시(추후)

## 기능 요구사항
| ID | 요구사항 | 수용 기준 | 우선 |
|---|---|---|---|
| F-01 | GPS 속도 측정 | OS 도플러 속도(m/s) 1초 간격 → kph. 값 없을 때만 거리÷시간 | P0 |
| F-02 | 속도 필터링 | 저정확도 샘플 폐기, 최근 3~5개 EMA. 마지막 갱신 3초 경과 시 "속도 없음" | P0 |
| F-03 | 기준 속도 설정 | 100/120/140, 기본 120, 재실행 후 유지 | P0 |
| F-04 | 초과 판정 | 기준 이상 2초 지속 → OVER, 기준−5 미만 또는 속도 없음 → NORMAL | P0 |
| F-05 | 차임 재생 | OVER 동안 루프, NORMAL 즉시 정지, 다른 앱 오디오와 믹스 | P0 |
| F-06 | 백그라운드 추적 | 화면 꺼짐·앱 전환 중에도 F-01~05 동작. 알림에 추적 중 + 종료 버튼 | P0 |
| F-07 | 주행 화면 | 현재 속도 크게, 기준 속도, GPS 상태, 화면 켜짐 유지 옵션 | P1 |
| F-08 | 미리듣기·음량 | 차임 테스트 재생, 앱 내 볼륨 | P1 |

## 비기능
- 정확도 ±3kph(개활지 정속), "참고용 속도" 고지 / 지연: 초과→차임 3초 이내
- 백그라운드: Android location FGS, iOS Background Modes(Location + Audio)
- 오디오: 내비·음악과 믹스/덕킹, iOS 무음 스위치에서도 재생
- 권한: 위치(사용 중) + 알림. Android 백그라운드 위치 권한 요청 안 함
- 개인정보: 위치 저장·전송 없음 / 안전: "안전 운전 보조용, 법적 속도계 아님"
- 음원: 자체 녹음 또는 두 음 합성 (`tool/gen_chime.py`)

## 기술 스택
Flutter · geolocator · (flutter_foreground_task) · just_audio · audio_session · Riverpod ·
shared_preferences · permission_handler · wakelock_plus · flutter_test + GPX · GitHub Actions + Fastlane.
최소 OS: Android 7.0 (API 24), iOS 15 (제안, 미확정).
